# PR screenshots

Images linked from pull request descriptions, one folder per pull request (`pr-<number>/`). Descriptions link to them through a commit, as `https://github.com/jkachhad/Stormhalter/blob/<commit>/pr-<number>/<file>?raw=true`, so they show to everyone who can see the pull request.

Add screenshots in new commits on this branch. Don't rewrite or delete it, or the pull requests lose their images.
