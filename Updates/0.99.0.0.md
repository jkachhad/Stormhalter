## Client
- The creature list sorts creatures by distance, then by an internal ID.

## Server
- Two-handed weapons block fully only when held in both hands.
  - With a non-weapon item in the other hand, they block half as well.
- Two-handed weapons need both hands to swing, throw or shoot.
- Hand blocking has the same hand requirements as two-handed weapons.
  - Gloves give their blocking bonus only if you can use them (i.e bound to you, of your alignment).
- Reverted a change that let left-hand blocks cancel right-hand blocks.
- Thieves can no longer hide while wielding two-handed weapons.
- Thieves can no longer hide near ruins.
- A successful stun always removes fear.
- A longer stun always adds a tick to a shorter stun.
- A shorter stun doesn't change a longer stun.
- Stun ticks last twice as long.
- Only the strongest heroes can wield the Black Broadsword in one hand.
