## WorldForge
- Fixed an issue where a terrain component could overwrite another component's pathing result.

## Server
- New `jumpkick` command for a jumpkick attack.
- Changed how much stamina jumpkicks cost.
- `fight` switches to the nearest creature of that name when your previous target is out of melee range.
- A fire effect dispels the fire effects already there.
- Casters and ranged attackers move to a safer spot before attacking.
- Better checks and messages when two players pick up or drop the same item.
- Fixed an issue where the hand skill protected against projectile weapons.
