## WorldForge
- WorldForge has many improvements from korazail.

## Server
- Wands are now melee weapons, and all existing wands were removed.
  - They deal 1 to 2 piercing damage by default.
  - They can be belted or put in your backpack.
- The 18 strength quest, contributed by Leolus.
  - For testing, any profession can interact with its NPC.
- Contributions and fixes from Zrikz and Brick to their lands.
- Items no longer bind to non-player creatures.
- Attacking an immune enemy with a spell shows that it hit for little damage.
- Balms no longer last through death.
- Adjusted Turn Undead's damage scaling.
- Turn Undead returns mana instead of health.
- You get a message when a spell's effect wears off (i.e `The spell of Shield has worn off.`).
  - If an item still gives the effect, it stays as a spell status.
- Spell buffs and ticks, decay, combat and regeneration timers follow the facet's timer.
- Eating mugwort lowers all poison potency to 5, instead of lowering it by 5.
- Creatures no longer cast spells that would fizzle where they aim (i.e salamanders know Wall of Fire fizzles on water).
- Creatures ignore terrain created by illusions.
- Creating more summons no longer kills followers that weren't summoned.
- Fixed an issue where instant spells could be cast without enough mana.
- Fixed an issue where item teleporters didn't work for their item type.
- Fixed an issue where weight didn't update when dropping or splitting items.
- Fixed an issue where equipped, inactive recall rings activated when the server restarted.

## Oakvael
- New contributions from SewerCzar to the Grove, which can change the map as you play.

## Collaborators
- `Wand` now inherits from `MeleeWeapon`, and deals 1 to 2 piercing damage unless overridden.
- Fixed an issue where types defined in a mapproj were resolved from an earlier build after a restart, causing type mismatches.
  - For example, `ObsidianEgg` from `AxeGlacierA.dll` instead of `AxeGlacierB.dll`.
