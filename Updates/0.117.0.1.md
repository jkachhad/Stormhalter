## Client
- The client now checks for a new version when it starts and updates itself.
  - You no longer need to run the updater yourself. The client closes, the updater installs the new version, and the client starts again.
  - If something goes wrong, its window now stays open so you can read the error.
- Fixed an issue where a damaged game content file stopped the client.
