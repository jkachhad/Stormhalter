## Client
- The settings window has an option to record gameplay.
- The client can render fullscreen.
- The conference window has an exit button.
- You can start dragging an item from the transparent areas of its slot.
- The beneficial target cursor works on the paperdoll button.

## Content
- Poison Cloud is semi-transparent.

## Server
- New `help` command lists the conference and world commands. Some are experimental.
- Poison Cloud and Whirlwind always face the last direction you give.
  - They're centered on the furthest visible step (i.e `E E S` with `E E` out of sight centers on `E`, facing south).
- Closed doors take slightly higher priority over walls.
- Spell effects on the map don't trigger on dead creatures.
- Blind, Stun, Fear and Poison reset when you're resurrected.
- Fixed an issue where resurrection penalized your two lowest skills instead of the highest.
- Fixed an issue where regeneration didn't reset properly after resurrection.
- Fixed an issue where `fight` locked your round when its target wasn't there.
- Fixed an issue where some failed `cast` commands locked your round.
- Fixed an issue where targeting by command didn't find a target by name.
- Fixed an issue where stun messages weren't shown properly.
- Fixed an issue where health states updated only on damage, not on healing.
- Fixed an issue where base dodge counted twice, overshadowing other defense sources.
- Fixed an issue with staircases within the same segment region.

## Collaborators
- New sandbox command `gold` creates the amount of gold you give, 1000 by default.
