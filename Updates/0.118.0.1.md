## Server
- Typed pet orders work again, alongside the Shift+Right Click menu.
  - `<pet>, follow`, `1, attack <name>`, `all, stop` and the other orders work as they did before v0.118.0, and so do macros that use them.
  - `<pet>, follow <name>` has a pet follow someone else, which the menu can't do.
- Fixed an issue where Knights couldn't start Cudyl's quest, because his menu showed its entries to every profession except Knights.
