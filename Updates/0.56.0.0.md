## Client
- Fixed an issue where the wrong hotkey was assigned to looking at the ground. It's `Alt + Z`.
- More hotkeys are supported.

## Server
- Fixed an issue where items bought from merchants decayed.
- Fixed various visibility issues for entities out of line of sight.
- Hoodwink has intensities, and can be pathed from Obscurer of Ways (7).
  - It takes gold from several places.
- Backstab, an experimental Thief spell for an instant attack.
- When an attacker knocks you prone, your round timer restarts.
- Fixed an issue where you couldn't path over trash barrels.
- All counters have a `look` action.
