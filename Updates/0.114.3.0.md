## Client
- The updater (`Kesmai.Update`) is now version 1.5.
  - It checks your CPU (x86 or x64) and that the .NET 8 Desktop Runtime is installed.
  - It deletes files that are no longer needed, and downloads the whole file when a patch fails.
- Right-click quick-inspects again, as it did before interactions, and Shift+Right Click opens the interaction menu.
- Fixed an issue where Peek, Wizard's Eye and Thief's Eye didn't switch your view.
- Fixed an issue where hovering a creature in the creature list didn't show its name on the map.
- Fixed an issue where targeting blocked commands that lift or drop items.
