## Client
- Replays can be stepped through by frame or by single packet, for debugging.
- Fixed an issue where removing an inactive Recall Ring left a graphical artifact in the ring slots.

## Server
- World saves are backed up every hour.
- Improved the tick rate for creature AI.
- Lawful, chaotic/evil and neutral weapons help only if your alignment matches.
- Lawful weapons give an extra attack bonus against evil creatures.
- Items decay 1 hour after they were last moved. Corpses are stripped before they decay.
- Dragon and Salamander corpses are immune to fire.
- Peek dispels itself after 15 seconds.
- Fixed an issue where Wizard's Eye didn't update the world map and creature list properly.
- Fixed an issue where creatures could jumpkick or shoot while stunned.

## Collaborators
- Fixed a crash when using `go` with text. You can no longer teleport to invalid regions.
