## Client
- The server's command aliases are now client macros, and can't be edited.
  - Macros should always use the full command.
  - `c` = `cast`, `cu` = `climb up`, `cd` = `climb down`, `d` = `down`, `f` = `fight`, `jk` = `jumpkick`, `m` = `move`, `o` = `open`, `r` = `rest`, `t` = `take`, `th` = `throw`, `u` = `up`, `w` = `warm`.
- Fixed a crash when re-entering Tortuga.
- The updater shows progress bars.

## Server
- Aging attacks.
- Troll Temple and Oak Undead spawns.
