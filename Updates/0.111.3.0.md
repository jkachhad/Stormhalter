## Client
- Chat has a new look and new settings.
  - All chat settings are in one window (the chat bubble icon in the top panel), and each chat tab can have its own icon.
  - Timestamps can be turned on, in several formats. Frames can go transparent while the text stays opaque.
  - Each channel is one checkbox, party speech is on by default, and "Reset Position" moves a tab back to the first frame.
- Cancelling a spell in the UI no longer costs a round.
- The cursor shows whether a target is valid (+) or not (X).
- When you target a path, double-clicking a creature no longer targets it (it sent your own hex as the path).
- The paperdoll button ignores clicks while you're targeting.
