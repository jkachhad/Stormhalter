## WorldForge
- The selection (arrow) tool shows more clearly when you're appending to or joining selections (hold `Shift`).
- Drag inside a selection with the arrow tool to move it.
- Holding the left mouse button keeps drawing as you move the mouse.
  - Each press acts on each tile at most once.
- When there are selections, the draw tool works only inside them.
- New Paint tool fills selections: click to replace, `Shift`+click to append.
