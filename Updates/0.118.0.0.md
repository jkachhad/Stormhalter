## Client
- Stormhalter now runs on Linux (64-bit).
  - Download https://www.stormhalter.com/release/stormhalter-linux-x64.tar.gz, extract it, and run `Kesmai.Client`. It updates itself and its game content, like the Windows client.
  - Your settings, hotkeys, macros, chat logs and replays are kept in `~/.local/share/Kesmai`.
  - WorldForge is still Windows only.
- The settings and login windows now shrink to fit small screens (i.e the Steam Deck).
- If a game content file is missing or damaged, the client now draws a magenta and black checkerboard in its place instead of crashing.
- Books, scrolls, and the Locate and Peek spell windows now close with right-click or `Escape`.
- Fixed an issue where a macro without a space before the `=` (i.e `tda=throw dagger at`) lost the last letter of its name.
- Fixed an issue where a macro containing `[0]` crashed the client when entering the world.

## WorldForge
- Map edits can be undone with `Ctrl+Z` and redone with `Ctrl+Y`. The window title shows when the segment has unsaved changes.
- A Fill tool fills a connected area of matching tiles.
- A Problems panel lists map issues, such as teleporters to missing places, and jumps to them.
- The Entities editor has an OnSpawn asset panel, and a Builder that writes a creature's OnSpawn from a form. The Body and Hue tabs are now one tab with a preview.
- New Quest Maker, Item Maker and Weapon Maker, and a Dialogue tab for a creature's Shift+Right Click options.
- The start screen has Create Segment and Open Segment buttons.
- Fixed an issue where teleporter destinations with a zero coordinate were dropped on save.
- WorldForge needs the latest .NET 11 Desktop Runtime (x64). If it doesn't start, install it again from https://dotnet.microsoft.com/download/dotnet/11.0

## Server
- More townsfolk commands are now in the Shift+Right Click menu.
  - Long menus are grouped into submenus, i.e `Sell ▸`, `Teach spell ▸` and `Critique skill ▸`.
  - Bankers: `Deposit all`, `Deposit…`, `Withdraw…` and `Show balance`. Amounts are typed into a window in the middle of the screen.
  - Shopkeepers: `Sell ▸` lists each item in stock with its price.
  - Weapon trainers: `Critique skill ▸`, `Critique training ▸` and `Train an amount…`.
  - Spell trainers: `Critique training` and `Teach spell ▸`.
  - Bankers, shopkeepers and trainers still understand the typed commands.
- Questkeepers now list their quest in their menu (i.e `Teach`), and answers such as `Yes` and `No` only while they are waiting for one.
  - Saying `teach`, `yes` or `no` to a questkeeper no longer does anything.
- Pets now take their orders from their menu.
  - `Follow`, `Trail`, `Attack`, `Stop`, `Release` (summoned creatures), `Take ▸`, `Drop ▸`, climbing and stairs, and `Move…` to walk a path such as `n ne e`.
  - Your own menu has a `Followers ▸` submenu that orders every follower in sight.
  - Typed pet orders (i.e `<pet>, follow`) have been removed.
- These typed commands have been removed; use the menu instead: `sell book` (profession trainers), `sell ring` (the Knighthood teacher), `forgive me` (the confessor ghost) and `craft broadsword`.
- The Identify spell and the Vermeil Ring now ask you to target an item, so you can identify items anywhere in your inventory, not only in your right hand.
- Fixed an issue where using a wand, or a weapon that casts a spell when it hits, cancelled the spell you had warmed.
- Fixed an issue where a destroyed wall could still block movement.
- Fixed an issue where declining a quest and asking again could crash the server.
  - A declined quest no longer shows as in progress after a server restart.

## Staff
- The properties window (`props`) has been redesigned.
  - Each row has one arrow, which edits the value or opens it. A plus creates a new value.
  - Objects inside a property (i.e a weapon's poison) and lists can be opened. Lists show 50 entries per page.
  - Properties above your access level are hidden.
- Game masters can read and change properties from the input line.
  - `get Health MaxHealth` - shows the health and maximum health of what you target.
  - `set Name "Old Tom" Health 5` - changes two values at once.

## Collaborators
- NPC speech commands are being replaced with Shift+Right Click entries.
  - Questkeeper's `teach`/`yes`/`no` speech is gone. List your quest entries in `GetInteractions` with `Questkeeper.QuestInteraction`.
  - Building blocks: `InteractionSubmenu`, `VendorInteraction`, `VendorActionInteraction`, `ExchangeItemInteraction`, `UpgradeQualityInteraction`, `InputInteraction` and `StaffSubmenu`.
  - Pets add orders in `GetOrderInteractions`. Escorts use `IsEscort`, `CanBeEscortedBy` and `OnEscort`.
  - Gumps can now be closed by default. Read `Documentation/Kesmai.Server/Gumps.md` for `CanClose`.
