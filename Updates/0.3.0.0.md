## Client
- A new compression library makes patches smaller.
- Dropping an item from one container onto an occupied slot of another puts it in the next free slot.

## Content
- Ice and fire breath have sound cues.
- Fewer sounds play for similar effects.
- Shield has the same sound cue as other protection spells.
- Fixed an issue with chant sounds for NPCs.

## Server
- Poison Cloud and Whirlwind don't pass through closed doors.
- Enchant and Venom last through server restarts.
- Fixed a crash with Summon Rat.
- Fixed an issue where Summon Rat didn't give the caster control.
- Fixed an issue with magic skill gain.
- Fixed a crash with damage ticks after Fire or Ice is dispelled.
- Fixed an issue where Icestorm didn't place when cast at power level 1.
- Fixed an issue where Protection from Fire/Ice caused an infinite round.
