## Client
- `F1` no longer opens the wiki.

## Server
- Players can use `DebugCombat` during this testing phase.
- Players can use `props`, read-only.
- Agate drops for any Knight on the Knighthood quest.
- You can't attack through walls (i.e with Perception).
- `shoot` unnocks projectile weapons only after the attack.
- Tiles that don't exist show as empty in your vision.
- Possible fix for items rolling back.
- Fixed an issue where old items were saved even when no player held them.
- Fixed an issue where the ice protection ring wasn't a ring. Existing ones may be deleted.
- Fixed a crash when leaving or entering invalid tiles.

## Collaborators
- New `CreatureEntity.GetFriendlyInRange`.
- Fixed an issue where `CombatAI` didn't execute instant casts properly.
- `CasterAI` moves to a safe location only when other creatures are around.
- `RangedAI` nocks its bow before wandering.
