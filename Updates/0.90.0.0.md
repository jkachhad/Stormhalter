## Client
- New UI design and artwork.

## Server
- All permadeath characters are now locked to the Jade facet.
  - Jade has double experience and skill gains, and 1-second rounds.
  - Bloodlands, Blackburrow and Razalas Peak aren't available in Jade.
- Removed the Beryl facet.
- New `leaderboard` command.
- Illusions cast in town last only 5% of their duration.
- Clients are disconnected after 10 minutes in the game, and after 15 minutes in the conference room.
- Windows sent by the server are compressed.
- Hostility is worked out differently, which should fix `*` attacking other players.
- Fearing a creature that has 0 movement no longer makes it move.
- Fixed an issue where Thieves with Perception weren't blinded properly.
- Fixed an issue where the dexterity bonus didn't apply to hand AR.
- Fixed an issue where some emotes played the wrong female sounds.
- Fixed an issue where the pet command could disconnect you.

## Staff
- The `props` window always lists properties in alphabetical order.
