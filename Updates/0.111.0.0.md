## Client
- Only one copy of the client can run at a time, to prevent multi-boxing.

## WorldForge
- Global drops (hoards) are in the Treasures tab. A hoard's drop chance can change by facet and region, and hoards go on every hostile creature that gives experience.

## Server
- Dying no longer costs attributes, only health and stamina.
- Attribute potions are now uncommon drops, around 1 in 10,000, and more common in harder areas.
  - All 9,738 existing attribute potions were deleted, along with the ones bosses dropped (i.e Ydnac, Shidosha, the Twins, the Giant).
  - Vendors stock them at 1% instead of 10%, and Ianta gives Mana potions instead of a Willpower potion.
