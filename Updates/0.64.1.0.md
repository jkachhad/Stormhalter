## Client
- Fixed a crash when several dialog windows were open.

## Server
- Fixed a crash after dying and having your corpse moved.
- Fixed a crash when moving into walls.
- The server sends fewer visibility updates.
  - While you move, only when your tile changes.
  - Only once, even when two or more visibility changes happen together.
- Fixed an issue where treasure visibility didn't update on the map until you moved.
- Fixed an issue where Dispel Illusions didn't dispel illusions.
- Similar illusions dispel each other.
- Illusions dispel on their own, scaling with skill level.
- Create Illusion can make various new terrain types at higher skill levels.
- Obstructions are marked as impassable.
