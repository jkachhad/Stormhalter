## Client
- Fixed an issue with pathing into doors.

## WorldForge
- `ExperienceMultiplier` and `HealthMultiplier` can be set per region, on the Segment tab.
- Fixed an issue where entities and treasures weren't resolved when referenced in scripts.
- Terrain draws in the proper order, whatever the order of its components.
- All existing sprites are sorted into categories and components.

## Kesmai
- Kesmai -1 has 40 spawns instead of 50.

## Collaborators
- Any weapon can have its own swing delay, not only The Hummingbird Sword.
- Shopkeepers can be set up to sell items to players, with a `RestockDelay` (see the `kesmaiWeaponsmith` and `kesmaiArmorer` spawns).
  - Stock with `shopkeeper.Stock<Dagger>("dagger", 100)`, `shopkeeper.Stock<ClearBalm>("balm", 16, 30)` or `shopkeeper.Stock("sword", () => new ShortSword(), 300)`.
  - Restock with `shopkeeper.Restock()`, `shopkeeper.Restock(StockEntry entry)` or `shopkeeper.RestockAll(bool maximum = false)`.
- `Kesmai.mapproj` is open source, and merge requests to it go into the master branch.
