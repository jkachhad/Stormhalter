## Client
- Pressing `Enter` in the Peek and Locate windows presses `OK`.
- Input is ignored while the game window isn't active.

## Server
- Disintegrate no longer removes items above common quality.
- Aging has a new middle-aged period, so reaching old age takes twice as long.
- Without adventurer status, magic and combat skills gain at 25% of the normal rate.
- Gauntlets check your alignment when used.
- Robes and weapons give their mana regeneration bonus only if you can use them.
- Turn Undead returns mana only when it does damage.
  - The mana returned is calculated differently.
- Illusions no longer have any effect while their caster is offline.
- Casting Venom with no weapon brings up a target.
- Recalling updates your vision properly between segments and similar tiles.
- Creatures can wander between separated bounds.
- Fixed an issue where poison potency could go negative.

## Collaborators
- `Profession.RestrictSpellcast`: a profession set to `true` can't cast with any equipment that has `RestrictSpellcast` set to `true`.
