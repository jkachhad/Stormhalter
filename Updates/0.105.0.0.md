## Client
- The Resolution setting is replaced by Game Scale and UI Scale. Game Scale 2.0 and UI Scale 1.0 are recommended; UI Scale does nothing yet.
- Repeated messages are batched in the log (i.e `Orc misses. [x3]` means three orcs missed you), which cuts network traffic, spam and replay size.
