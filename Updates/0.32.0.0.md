## Client
- Fixed an issue where the character sheet button took focus.

## Content
- Fixed an issue where a nocked bow had the wrong art.

## Server
- All characters start with 50 gold in their backpack.
- Merchants limit how much they sell of items such as balms and recall rings.
- Permanent attribute potions have prices and weights.
- Find Secret Doors tells you when there are no doors, instead of fizzling. It gives no skill.
- Sage, on Discord, has new commands.
  - `!reply` replies to GitHub issues without needing an account.
  - `!online` shows where clients are connected.
- Fixed an issue where opening a locker could lock your round forever.
- Fixed an issue where gold could be put in your lockers.
- Fixed an issue where an instant-cast spell's target couldn't be held while you waited for mana to regenerate.

## Leng
- Fixed an issue with the portal gem teleporters and shimmering veils.
- Fixed an issue with the portal to Shidosha that only Martial Artists and Thieves can use.

## Bloodlands
- Bloodlands, a new experimental segment by Zrikz, is open to explore.
  - It appears deserted for now.
