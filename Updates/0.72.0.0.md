## Client
- A report button in the client creates GitHub issues.
- Fixed an issue where up and down didn't cycle through command input properly.
- Prevented a client crash. Creatures that would have caused it show a gray status instead.

## Server
- Fall damage is now twice the distance fallen, instead of half.
- Topaz rounds are now like Ruby's, instead of 2.5 seconds.
- `played` includes your current session.
- You can interact with every item on a counter or altar (i.e `search`).
- Shopkeepers understand item names of several words.
- Magic-immune creatures no longer avoid fire and ice.
- Creatures that see less than 3 hexes move away to cast spells.
- Fixed an issue where newly spawned groups didn't get proper round timers.

- The apothecary sells potions.
