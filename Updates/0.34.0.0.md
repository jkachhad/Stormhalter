## WorldForge
- Hotkeys for the filters (`F1`–`F8`) and the tools (`1`–`8`).
- Copy and paste works between separate WorldForge sessions.
- `.mapproj` files no longer store default values, so they're smaller.
- `Escape` closes any open editing window.
- The draw tool ignores single-tile selections.
