## Server
- Fixed an issue where stun wasn't removed on its last tick.
- Concussion, Lightning Bolt and Hide Door are no longer limited to paths in line of sight.
- Opal is no longer an active facet.
- Two-handed weapons can be wielded and swung with one hand.
- Longbows and shortbows un-nock when they're moved or you move. Crossbows don't.
- Projectile weapons need a free hand to be nocked.
- NPCs no longer drop their two-handed weapons.
- Some items can be thrown from the top 5 backpack slots (i.e weapons, Naphtha, Nitro).
