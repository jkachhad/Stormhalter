## Client
- The client now runs on .NET 11 and MonoGame 3.8.6 and ships as a single native executable.
  - You no longer need to install the .NET Desktop Runtime to play.
- The updater has been upgraded to version 1.7.
  - All downloads now use HTTPS, and every file is checked with SHA-256 before it is installed.
  - Only files that have changed are downloaded, and a failed download is retried. Older updaters update themselves to 1.7 on your next launch.
- Game content is now updated when the client starts, rather than by the updater.
  - Only changed content is downloaded. If the update fails, the game starts with the content you already have.
- The default UI font is now Roboto Slab Medium, and text is drawn sharper.
  - Outlined and shadowed text no longer cuts notches into neighboring letters (i.e `ff`, `rn`, `AV`).
- You can now press `Enter` in the password field to log in.
- The text cursor is now visible in empty text boxes.

## WorldForge
- WorldForge now runs on .NET 11, ships as a single file, and is much faster when drawing, erasing and scrolling the palette. It still needs the .NET 11 Desktop Runtime.
- Fixed an issue where region bounds dropped tiles on save.
- Fixed an issue where Erase and Hammer picked the wrong tile when zoomed or offset.
- Fixed an issue where terrain filters, and the comment icon check on brush tiles, could crash.

## Server
- Fixed an issue where your current health, stamina, or mana could stay above your maximum after removing an item or losing an effect that raised it.
  - Raising your maximum still does not refill you.

## Collaborators
- Equipment stat bonuses have been reworked. If you override item stat bonuses, read `Documentation/Kesmai.Server/StatModifiers.md`.
