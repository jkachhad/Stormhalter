## WorldForge
- Fixed an issue where the Tools and Filter selections didn't update.
- Fixed various issues left by the rendering and UI changes.
- Right-clicking a region map opens a menu of quick actions.
  - It can create a spawn or a location on the tile you clicked.
- Spawners have two new triggers, `OnBeforeSpawn(Spawner)` and `OnAfterSpawn(Spawner, MobileEntity)`.

## Server
- Fixed an issue where negative price modifiers raised the price of items.
- Fixed crash recovery when scripted assemblies were still locked by the previous instance.
- Fixed an issue where GitHub commands didn't run properly.
- `!online` takes `facet` or `segment` (i.e `!online segment`, `!online facet`).
