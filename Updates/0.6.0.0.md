## Client
- Items go to random positions when all slots are full.
- Input passes through items and container slots where needed.
- Fixed an issue where items couldn't be equipped in the last portrait slot.

## Content
- Fixed an issue with the spell icon for the Stun and Death Protection status.
- Fixed an issue with the sounds of summoned Phantoms, Djinns and Efreets.

## Server
- Portals cause damage when dispelled.
- Destroyed walls no longer block line of sight.
- You can't leave the world while feared, stunned or blind.
- Swinging or throwing a projectile weapon does little damage.
- Summon Phantasm summons at most 3 creatures in all.
- Phantasms no longer leave corpses.
- Thieves no longer have Darkness (1).
- Fixed an issue where critiquing rounded skill levels to whole numbers.
- Fixed an issue with some item labels.
