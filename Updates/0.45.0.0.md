## Client
- Fixed an issue with how the client and server handle closing dialogs.

## WorldForge
- Fixed an issue where DPI scaling broke input on 4K monitors.

## Server
- Fixed an issue where instant spells weren't cancelled when you cancelled the target or dialog.
- `warm <spell> [power]` starts warming a spell (i.e `warm fireb 2` for Fireball at power 2).
  - Without a power it warms at maximum power, and with `0` at minimum power.
- Various beneficial spells send a `self` target to the caster (i.e `cast at self` works like `cast`).
  - One macro can then take an optional target (i.e `cat` = `cast at [1:self]`).
- Instant spells can be cast with `cast` (i.e `cast cure at self`, `cast light at n n n`).
- The Knight's Light spell also dispels spider webs.
