## Client
- The client ignores DPI scaling.
  - The game draws smaller, so raise your resolution.
- Fixed an issue where dragging locked up when a spell fizzled while targeting.

## Server
- Draznia, Mnar and Leng Thieves start with a crossbow in their belt.
- The Thaumaturge spell Cure is now called Heal, so it doesn't clash with `cast` commands (i.e `warm heal`, `cast heal at self`).
- Heal and Raise Dead staves.
- All creatures are immune to damage from their own spells.
