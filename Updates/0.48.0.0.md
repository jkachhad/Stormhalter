## Client
- Fixed an issue with full-screen mode.
- 16:9 screens are letterboxed to draw the game at 4:3.

## Content
- Fixed an issue where some ruins and walls used in Oak undead drew in the wrong order.
- Fire has an extra layer that draws over destroyed walls.
- Fire's animation step is 80 instead of 140.

## Server
- Spell orbs of Create Web, Light, Fireball, Icestorm and Darkness.
- Spell wands of Ice Storm, Fireball, Lightning, Create Portal, Death, Blind and Fear.
- Fixed an issue where spells could path through walls.
- Fixed an issue where normal Liches weren't immune to ice.
- Creatures with similar alignments never attack each other.
  - Lawful and neutral creatures may attack other lawful or neutral ones when defending.
- `cast` with instant spells (Knights) no longer needs `at` before a path (i.e `cast light w w`).
- `cast` casts spells from wands, left before right (i.e `cast fireball e e` with a fireball wand, `cast death at orc` with a death wand).
  - Wands are used first, even when you've learned the spell.
