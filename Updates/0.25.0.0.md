## Content
- Darkness tiles are semi-transparent.

## Server
- New `played` command shows your total played time on each character.
  - It's inaccurate for characters created before this patch.
- Poison Cloud also affects creatures that walk into it, not only those there when it's placed.
- Poison Cloud gives a saving roll against blindness.
- Stunned creatures can't make secondary blocks (i.e paws, beaks, tails). Primary blocks such as hide and armor still happen.
- NPCs ignore orders that other NPCs handle. Subordinates follow regardless.
- NPCs cancel their warmed spells when they lose their target.
- When a player's corpse decays, the ghods resurrect them.
- Fixed an issue where spells couldn't be cast over segment portals.
- Fixed an issue where light cycle messages showed twice.
- Fixed a crash when Djinns or Efreets cast spells.

## Kesmai
- Changed the difficulty of Trog and Daisy.
- Fixed an issue with the destructible pillars on Kesmai -4.

## Leng
- Changed the difficulty of Kosh.
- Some landscape changes.
- Fixed an issue with Leng's facet, entrance and resurrection locations.
- Fixed an issue with several ropes.
