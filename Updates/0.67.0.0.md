## Client
- Fixed an issue where spell inscriptions dropped between bars didn't drop or draw properly.
- The portrait panel shows slot titles.
- `Enter` and `Escape` work in the item amount window.

## WorldForge
- Rope and Shaft components have a `SlipChance` property.

## Server
- Balms tick at a third of the facet's round timer.
- Fixed an issue where selected attacks weren't used in damage calculations.

## Collaborators
- New types `Cat`, `Duck`, `Hippopotamus`, `Panda`, `Fish`, `Raven`, `WaterElemental`, `Mummy`, `TrollGuard` and `Overlord`.
- All animals inherit from `AnimalEntity`, and have `CanLoot` set to false.
- `SpellHelper.GenerateMantra` generates mantras and chants.
  - `SpellHelper.GenerateMantra(byte first, byte second, byte third, byte fourth)`
  - `SpellHelper.GenerateMantra(params byte[] words)`
