## Client
- Fixed an issue where renaming a character could lose its hotkeys.

## Content
- The original female Thief sprites are back in place of the experimental ones.

## WorldForge
- A segment's parts are now organized in a tree, with components, brushes and templates (`SegmentComponent`, `SegmentBrush`, `SegmentTemplate`).
  - Its C# code is in a sources folder, to edit with an external IDE, and a NuGet package works as a reference.

## Server
- Game accounts are now linked once to a Discord account, for moderation, security, guild management and celebration messages.
  - Only Discord users with a verified email who are on the Stormhalter Discord can play.
  - Linking changes nothing on your Discord account: only your Discord ID is stored.
