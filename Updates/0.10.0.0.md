## Client
- The network protocol has a version, so it can change later without breaking replays.

## Content
- Fixed an issue where swinging projectile weapons played the wrong weapon sound.

## Server
- A tailor has moved in and sells armor, scales and jackets.
- Chainmail and Platemail block spellcasting.
- A message tells you when a spell's buffs wear off.
- Creature AI picks, prioritizes and times its spells better.
- Creatures use blind, fear and stun spells better.
- Items can be inspected from up to 1 tile away.
- Fixed an issue where creatures didn't regenerate mana, stamina and health.
- Fixed an issue where flying creatures were affected by water.
- Swimming creatures can drown, but flying creatures can't.
- Fixed an issue where spawns weren't randomized properly.
- Fixed an issue where respawns didn't trigger properly.
- Fixed an issue with which tiles spawn areas include and exclude.
- Fixed an issue where item descriptions weren't localized properly.
- Fixed several line of sight and visibility issues with darkness.
- Fixed an issue where emote and action commands locked your round.
