## Client
- New latency indicator between the client and the game server.
- Fixed crashes with the creature list and its sorting before map updates.

## Server
- Items decay after 1 hour instead of 15 minutes.
- Creature AI ticks every 5 ms instead of every tick.
- Fixed an issue where the server sent updates for creatures you couldn't see, which crashed the creature list.
  - For example, casting Fireball on a spectre that wasn't on your creature list.
- Fixed an issue where items kept saving after being dropped from a character.
- Fixed an issue where loot that didn't fit in a backpack didn't drop.
- Fixed possible crashes with the `begone` order and the `break` command.

## Staff
- New `!announce` Discord command for the adventurer role and above.

## Axe Glacier
- Added the obsidian egg for the Returning Axe quest.

## Collaborators
- `AddWeakness(Type type)` and `AddImmunity(Type type)` take item types (i.e `iceDragon.AddWeakness(typeof(SilverGreatAxe))`).
- `Backpack.IsStrict`: when `true`, only certain contents can be stored.
- Inventories depend on the entity type.
  - `AnimalEntity`: a backpack (not strict).
  - `MobileEntity`: paperdoll, rings, backpack (not strict), belt and hands.
  - `PlayerEntity`: paperdoll, rings, backpack (strict), belt, hands and locker.
- Items defined in map projects resolve properly when loaded from saves.
