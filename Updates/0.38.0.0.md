## WorldForge
- `HiddenTeleporter` can be set to teleport non-players, and by alignment.

## Server
- Fixed an issue where teleports also teleported NPCs.
- Added the Knight's Halberd and the Lightning Resist Ring.
- Fixed an issue where fire and ice amulets didn't spawn with the right charges.
- Creatures led out of their home region wander freely.
- Creatures casting instant spells no longer move away from their target.
- Salamanders no longer need a valid path to aim Wall of Fire at their target.
- Hostile creatures can no longer enter certain thief areas.

## Oakvael
- Fixed an issue where Oakvael vipers spawned lawful.
