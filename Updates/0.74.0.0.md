## Client
- Two buttons at the top left toggle types of logging, one of them for combat messages.
- `Esc` clears the target, then any path, then any command input.
- Numpad `/` runs `throw`, but doesn't throw your weapon automatically.

## Server
- `throw` brings up a target for a matching item in your hands (i.e `throw dagger`), and `throw` alone for a throwable weapon.
- Creatures go inactive by region.
  - A region wakes when a player or their follower moves in, and while it's under Peek.
  - Regions go inactive on the facet's delay.
- Each facet adds a round handicap to creature turns: 90 ms in Agate and Beryl, 60 ms in Pearl and 45 ms in Ruby.
- Each creature's first round is delayed randomly, so creatures in a group rarely act at the same moment.
- Saves run in the background, which should end the lag spike once a minute.
- The ghods forgive all deaths during beta testing.
- Visibility changes for better performance.
- Fixed a few common crashes.
- Fixed an issue where vendor items didn't match their list numbers.
