## Client
- Dragging and dropping has been rewritten. It should work as before, so report anything missing.
- Chat frames, so speech and combat can have their own tabs.
  - Right-click a tab for its settings: which messages it shows, font size, backdrop and opacity.
  - Frame settings, position and size are kept per character. Delete the bin file in the Chat folder to reset them.
- The client window remembers its place and size on your desktop, and the game window its place in the client.
