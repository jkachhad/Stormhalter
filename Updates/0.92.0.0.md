## Client
- Fixed a crash when dragging gold into your backpack.

## Server
- Leaderboards show kills and deaths.
- Fixed an issue where experience per hour on the leaderboards was inaccurate.
- Fixed an issue where total game time was calculated wrongly for offline players.
- `users` shows the players in your facet.
- Fixed an issue where `warm` didn't match several parameters properly.
- Resistance and Protection spells last twice as long.
- Darkness lasts 25% longer.
- A warmed spell fizzles when you disconnect, and no longer drains mana.
- A failed Knight spell gives the proper fizzle message and sound.
- Terrain spell effects dispel similar effects on the same hex.
- Adjusted the AR calculation for jumpkicks.
- Adjusted the armor bonus against weapons with several damage types.
  - The halberd, the bayonet hammer and the fan (as a weapon).
- All chest armor gives some damage mitigation.
- All shields now have some progression in projectile protection.
- Fixed the chance to fumble a weapon: 1 in 160 at level 3, down to 1 in 4000 at level 19.
- Regional spawners are weighted by density, so creatures tend to spawn farther from others.
  - A spawner counts only its own spawns, not the whole region.
- Creatures shuffle their combatants before applying their search strategy, so targets on the same tile aren't always picked in the same order.
- The server allows only 1 account to be created per IP.
- Fixed an issue where stuns, fleeing, blindness and similar effects made spawn timers run fast.
- Fixed an issue where night vision didn't reveal darkness more than 1 tile away.
- Fixed an issue where the lightning shield didn't give the Lightning Resistance status.
- Fixed an issue where passive teleporters didn't work.
- Fixed an issue with casting spells while observing others.
- Fixed a crash with an ancestor's recall ring.
- Fixed a crash when Whirlwind and Poison Cloud overlapped several times.

## Staff
- `!compile <mapName>` in Discord compiles a map, to test completed merge requests.

## Collaborators
- `IWieldable` calls `OnWield` and `OnUnwield` when the item is put in or taken out of a hand.
- Fixed an issue where inclusion and exclusion rectangles weren't calculated properly.
