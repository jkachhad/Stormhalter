## Client
- Items you're holding go back to where they came from when you move.
- Numpad `*` sends a `fight` command.
- Numpad `5` clears the command line.
- Fixed a crash when pressing `Tab` in gump windows.

## WorldForge
- WorldForge connects to the server for its data.

## Server
- An experimental ring. Inspect it and you see crashing ocean waves.
- Fixed an issue where creatures didn't pick up gems from Hoodwink.
- Fixed an issue where Hoodwink failed when pathed.
- Fixed an issue where a visibility range of 0 stopped some creatures from attacking.
- Fixed an issue where some command arguments were case sensitive.
- Right-hand blocks no longer happen while the left hand is blocking.
- Breaking treasure items gives experience, and breaking bound items gives more.
- Fixed the message shown when you're hit by Concussion.
- Fixed an issue where some robes were labelled "books" or "bottles" in tooltips.
- Fixed an issue where terrain didn't update properly when Perception wore off.

## Staff
- `props` can edit some properties.

## Underkingdom
- Fixed an issue where trees in Underkingdom didn't decay.
